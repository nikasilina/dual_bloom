ИИ: OpenAI Codex. Дизайн, концепция и визуальный стиль инструмента были разработаны самостоятельно. ИИ использовался только для технической реализации: настройки аудиоархитектуры, двух голосов, барабанов и эффектов, связывания интерфейса со звуком и исправления ошибок в JavaScript. Работа строилась через последовательные промпты с описанием необходимой механики.
